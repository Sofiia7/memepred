## Короткая версия

Непрерывный PvP up/down на градуированные токены лаунчпадов. Ставка в ETH, длительности
300 секунд по умолчанию (60/900 - отдельные эксперименты), цена - TWAP из собственного v3-пула токена, рынок на токен создаётся
один раз и permissionless для PvP, а доступ к общему LP включается владельцем хранилища
отдельно. Рейк при создании рынка - 1% с банка с потолком, зашитым в контракт.

Реализация - ветка `robinhood-chain` от `sprint-0-5-hardening` в этом же репозитории.
**Base не отменяется и не трогается:** схема аддитивная, новые контракты ставятся рядом
со старыми, кипер получает профиль цепочки. Критерий соблюдения - 276 forge и 222 vitest
теста, написанных для Base, проходят без единой правки в самих тестах. Подробности и
почему не отдельный репозиторий - `TZ.md` §0.

Проверка ветки 29 сентября 2026 (коммит `dd4df60`): `forge test --summary` - **433/433** (31 набор;
11 из них форк-тестов без `RHC_MAINNET_RPC` возвращаются пустыми и всё равно считаются пройденными),
backend Vitest - **439/439**, frontend Vitest - **692/692**; frontend также проходит `tsc -b` и production
build, в том числе отдельной сборкой под тестнет Robinhood Chain. Тестнет передеплоен из `271946a` (все
контракты верифицированы), на цепочке прогнан сквозной сценарий, кипер на сервере проверен отдельно.

## Три числа, которые всё определяют

- Газ исполнения на 4663 - **медиана 0.398 gwei** за сутки замера (04-05.09), хвост до
  3 gwei короткими всплесками, суточного цикла нет. Первые замеры 03.09 давали 1.7-1.8,
  то есть базовый уровень гуляет в разы. `eth_gasPrice` и `ArbGasInfo` 06.09 совпали
  (0.403 и 0.399), прежнее «занижает вчетверо» не подтвердилось. См. `measurements` §5.
- У `OrderbookMarket` **нет времени закрытия**, а `settleAt` ставится в момент матча.
  Значит один клон на токен живёт вечно, и весь рекуррентный расход - это была наша
  собственная политика ролловера.
- **`FEE_MAX = 100`** - протокол не может взять больше 1% с банка; новые рынки стартуют
  с этим тарифом, чтобы permissionless-вызов не закрепил нулевую комиссию навсегда.
