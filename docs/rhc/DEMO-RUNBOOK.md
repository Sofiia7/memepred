# Демо на Robinhood Chain testnet: как записать видео и что показать

Обновлено 2026-09-29. Всё, что нужно для записи и для сдачи на hackquest, в одном месте. Адреса и хэши - в
[`DEPLOYMENTS.md`](DEPLOYMENTS.md). Команды ниже написаны под cmd.exe, как ты работаешь.

## 0. Что должно быть готово до записи

| Условие | Как проверить | Если нет |
|---|---|---|
| DNS и сертификат API | `https://api-rhc.flipthememe.com/health` отвечает `{"status":"ok"...}` | Сделано 29.09. Если вдруг 525: у Caddy нет сертификата (см. `DEPLOYMENTS.md`, про 451). Если ответа нет совсем: проверь записи `api-rhc` и `rhc` в Cloudflare |
| Сайт открывается на `rhc.flipthememe.com` | главная с плашкой «ROBINHOOD CHAIN TESTNET» | Сайт уже выложен (`https://flipthememe-rhc.vercel.app`, проект Vercel `flipthememe-rhc`); нужен CNAME `rhc` в Cloudflare, см. `DEPLOYMENTS.md`, раздел «Сайт». Повторная сборка и выкладка описаны там же |
| Ты не в заблокированной стране | США, Великобритания и другие из списка увидят «REGION BLOCKED» и на фронтенде, и на API. Сингапур на RHC открыт (с 29.09) | Записывай из разрешённой страны или покажи сайт по видео |
| Кипер жив и с газом | `https://api-rhc.flipthememe.com/health/deep` возвращает `"status":"ok"` без `warn` | Пополнить `0xbFa008e5A8d46d2014b83551ce6209108416eea4` тестовым ETH; порог предупреждения 0.0006 ETH |
| Цена двигается | см. п. 1 | Без движения все ставки кончаются ничьей и возвратом |

## 1. Двигатель цены (стенд-ин пулы)

У тестнета нет настоящего Uniswap, поэтому цену пулов задаёт скрипт. В видео скажи об этом прямо: это
стенд-ины, цена на них искусственная, а контракты, расчёт по TWAP и деньги настоящие в смысле тестнета.

**Осторожно: этот двигатель нельзя гонять долго.** Стенд-ин пул хранит каждый сдвиг цены навсегда и перечитывает все
при каждой ставке и расчёте, поэтому каждый пуш добавляет к ним около 8.4 тысячи газа навсегда (29.09 пятьдесят пушей
подняли расчёт с 290 до 530 тысяч газа; сутки пушей раз в 45 секунд довели бы его до 14 миллионов). Для записи видео
хватает получаса с паузой 120 секунд, это около 15 пушей на пул. Скрипт сам останавливается после 60 пушей.

```
cd C:\Server\memepred
set RHC_MOVER_POOLS=0xfC5FB7d3B1DDFFc0b50b0CDDFFe3B016d4FF57cb,0xEFd4618F36268ce8c1c8Ad3783bdCa6185221dBd,0x779E9B50837478FcCD7DB50592eDB16ed45D8A18
set RHC_MOVER_EVERY=120
scripts\node_modules\.bin\tsx scripts\rhc\price-mover.mts
```

Останавливается `Ctrl+C`. Кошелёк берётся из корневого `.env` (`PRIVATE_KEY`, деплойер). Шаг не больше 0.4%, поэтому вход
не отклоняется проверкой «цена убежала от своего среднего на 2%».

## 1a. Живой трафик на рынках (скрипт, не пользователи)

Чтобы на сайте были объём, расчёты и выплаты, а у кипера настоящая работа, 29.09 запущен `scripts\rhc\soak-traders.mts`.
Раз в час три одноразовых кошелька ставят по 1-2 небольшие ставки (0.005-0.02 WETH) на каждый из четырёх рынков (на
FROGGO, где нет хранилища, два кошелька берут противоположные стороны), сразу после серии делают **один** шаг цены на
каждый пул, чтобы у ставок был победитель, забирают выигрыши и пишут отчёт. Шаги цены нормируются (не больше 150 за весь
прогон), потому что каждый навсегда удорожает газ пула, см. раздел 1. Без шага цены все матчи кончаются ничьей.

**Это не пользователи, и выдавать объём за трафик нельзя.** В видео и в заявке говори прямо: на тестнете активность
генерирует скрипт; настоящий показатель здесь - что расчёт, возвраты и выплаты идут сами и без сбоев.

Логи лежат в `scripts\rhc\` (`soak-out.log` с отчётом раз в 10 минут, `soak.log` то же построчно), ключи одноразовых
кошельков - в `scripts\rhc\.soak-wallets.json` (в git не попадает). Прогон идёт 24 часа с 29.09 11:42 UTC и сам
заканчивается; после перезагрузки компьютера запусти его заново: он подберёт недозабранные выигрыши. Точное запаздывание
кипера (по событиям цепочки, без погрешности опроса) и газ на расчёт: `scripts\node_modules\.bin\tsx scripts\rhc\keeper-lag.mts --hours 24`.
Остановить раньше (из cmd):

```
powershell -NoProfile -Command "Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -match 'soak-traders|price-mover' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
```

Продлить или запустить заново: те же скрипты, переменные `SOAK_HOURS`, `SOAK_CYCLE_MIN`, `SOAK_MAX_PUSHES` описаны в шапке
скрипта. Газ: у каждого из трёх кошельков около 0.0005 ETH в сутки, шаги цены платят они же.

## 2. Что показать, по порядку (около 4 минут)

1. **Проблема и пользователь** (20 с): краткий взгляд на мемкоины, «ставка на минуту без покупки токена».
2. **Главная**: три пула с названными токенами, у каждого «continuous» и подпись «each bet settles 1m/5m after
   it is matched». Плашка «ROBINHOOD CHAIN TESTNET» и «UNAUDITED, MAX BET 0.04 WETH».
3. **Кошелёк**: добавить сеть (имя Robinhood Chain Testnet, RPC `https://rpc.testnet.chain.robinhood.com`, chain id 46630,
   символ ETH, обозреватель `https://explorer.testnet.chain.robinhood.com`), получить тестовый ETH по ссылке «Get test ETH»,
   нажать WRAP (ставка идёт в стенд-ин WETH `0xaF3a...`, `deposit()` на нём открытый).
4. **Рынок MOONCAT 1m**: открыть блок «What you are agreeing to» (пять пунктов), сказать вслух: тайм-аут 5 минут, частичное
   исполнение, коридор цены, возврат обеих ставок при скачке больше 2%.
5. **Ставка UP 0.01**: три подтверждения (wrap, approve, bet). Хранилище берёт сторону сразу («matched by the vault»).
6. **Страница ордера**: обратный отсчёт «Result in mm:ss», потом результат и Claim. Открыть транзакцию по ссылке на
   обозреватель, показать `MatchSettled`.
7. **PvP на FROGGO 5m** (нужен второй кошелёк): ставка A UP 0.02, ставка B DOWN 0.01, у A половина исполнена; нажать
   «Cancel remaining»: 0.01 возвращается сразу. Дождаться результата (5 минут, в монтаже можно сократить с подписью «time
   jump»).
8. **Возврат при скачке цены** (30 с): показать на обозревателе уже готовую транзакцию `MatchUnpriceableRefunded`
   (`DEPLOYMENTS.md`, сценарий R): обе стороны получили ставку без комиссии за первый же вызов после `settleAt`, а не
   через сутки. Свежий пример можно получить командой `scripts\rhc\e2e-verify.mts` (7 минут).
9. **Доказательства** (30 с): восемь верифицированных контрактов, 433 теста контрактов, сквозная проверка с хэшами и
   газом, «кипер на сервере рассчитал сам» (`scripts\rhc\keeper-check.mts`).
10. **Что сделано за время buildathon** (20 с): назови честно, что проект существовал раньше, а за 13 сентября - 4 октября
    сделаны разбор аудита, немедленный возврат, `cancelOrder`, редеплой, интерфейс и его проверка.

## 3. Полезные скрипты

Все требуют корневой `.env` с ключами и тестовый ETH; ничего не печатают, кроме публичных хэшей.

| Скрипт | Что делает | Длительность |
|---|---|---|
| `scripts\rhc\e2e-verify.mts` | PvP + `cancelOrder`, выигрыш против хранилища, возврат при скачке цены; печатает хэши и проверяет суммы | около 7 минут |
| `scripts\rhc\keeper-check.mts` | ставки, которые может рассчитать только кипер на сервере; меряет запаздывание | 5-9 минут |
| `scripts\rhc\price-mover.mts` | двигает цену стенд-ин пулов; каждый пуш удорожает пул навсегда, поэтому по умолчанию 60 пушей и стоп | до лимита пушей |
| `scripts\rhc\soak-traders.mts` | раз в час серия ставок трёх одноразовых кошельков по всем рынкам и по одному шагу цены на пул, забор выигрышей, отчёт | `SOAK_HOURS`, по умолчанию 24 часа |
| `scripts\rhc\keeper-lag.mts` | точное запаздывание кипера по событиям цепочки и газ на каждый расчёт; только чтение | секунды |
| `scripts\rhc\economics.mts` | пересчёт таблиц `ECONOMICS.md`; с `--live` берёт свежие газ, цену ETH, балансы | секунды |

Перед запуском e2e и keeper-check задай адреса из `DEPLOYMENTS.md`. Пример для cmd:

```
cd C:\Server\memepred
set RHC_RESOLVER=0x8AC440A14610c685B2a59fBA4A2B3C62f8375E28
set RHC_LP=0x3695D11A79D7625a7126588Ad94b5878139409E2
set RHC_WETH=0xaF3aCfCE41417DE5C973cc214E170C73480b068a
set RHC_MARKET_LP60=0x2C179142844093BaEece809aE6F7Efb9c6a959C1
set RHC_MARKET_PVP=0x21995459f695c8Fc7BE072242000Cf3dfd14f0D2
set RHC_POOL_LP60=0xfC5FB7d3B1DDFFc0b50b0CDDFFe3B016d4FF57cb
set RHC_POOL_PVP=0x779E9B50837478FcCD7DB50592eDB16ed45D8A18
scripts\node_modules\.bin\tsx scripts\rhc\e2e-verify.mts
```

## 4. Если что-то пошло не так

| Симптом | Причина | Что делать |
|---|---|---|
| «Could not verify your region» | API `api-rhc` не отвечает | проверь `/health`: 525 значит у Caddy нет сертификата, а нет ответа - запись `api-rhc` |
| «REGION BLOCKED» | твоя страна в списке | записывай из другой; список не трогать |
| «entry price too volatile right now» | спот ушёл от 60-секундного среднего больше чем на 2% | подожди минуту, цена сойдётся |
| Ордер не рассчитывается больше 2-3 минут | кипер без газа или остановился | `/health/deep`; логи `deploy-rhc-keeper-1`; пополнить кипера |
| «not a real market» на странице рынка | адрес не создан текущей фабрикой | брать адреса рынков из `DEPLOYMENTS.md` |
| Возврат вместо результата | скачок цены больше 2% в конце окна или нет истории пула | это задумано: обе ставки вернулись без комиссии |
