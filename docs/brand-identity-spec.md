# FlipTheMeme — ТЗ на вордмарк/лого

Статус: сейчас везде плейсхолдер, сгенерированный скриптом
`scripts/generate-app-images.py` (Pillow, чёрный фон + текст JetBrains Mono).
Не финальный дизайн — держит место, чтобы Farcaster/OG-превью не были битыми
после ребрендинга с MemePred. Закрыть нужно до серьёзного паблика (мейннет,
CEF-подача, реальный трафик).

## Где используется

| Файл | Размер | Где показывается |
|---|---|---|
| `frontend/public/icon.png` | 1024×1024 | favicon, app icon |
| `frontend/public/icon-512.png` | 512×512 | Farcaster miniapp iconUrl |
| `frontend/public/splash.png` | 200×200 | splash-экран при загрузке mini-app |
| `frontend/public/og-cover.png` | 1200×630 | OG-превью (Twitter/Discord/линки) |
| `frontend/public/embed.png` | 1200×630 | Farcaster frame/miniapp embed-карточка |
| `frontend/src/components/ui/AppHead.tsx:14` | текст | шапка сайта, `<span className="name">` — сейчас просто текст "flipthememe", не картинка |

## Существующий визуальный язык (держаться этого, не изобретать заново)

- Фон: чёрный `#0a0b0d`
- Base blue `#0052FF` — основной брендовый цвет (вся типографика/лого)
- Синий `#4d8dff` = UP, розово-красный `#ff3d6e` = DOWN (реальные значения из
  `frontend/src/index.css`, переменные `--up`/`--down`) — единственные два места,
  где цвет несёт смысл (исход ставки). **Не использовать эти два цвета ни для
  чего другого** — в проекте это зарезервированные сигнальные цвета.
  ⚠️ Уже задеплоенные `og-cover.png`/`embed.png` и лого-мокап используют
  зелёный/красный (`#00ff88`/`#ff3355`) — это старые цвета из плейсхолдер-скрипта,
  ошибочно попавшие в первую версию этого ТЗ. Не переделываем задним числом —
  просто держим в уме на будущее: любой новый арт (включая NFT, см.
  `docs/nft-artwork-spec.md`, который прав с самого начала) должен использовать
  синий/розовый, а не зелёный/красный.
- Шрифт: JetBrains Mono (Bold) — моноширинный, техно-вайб, уже используется
  во всём интерфейсе, не только в лого.
- Мотив: свечной график / orderbook (полоски по краям иконки в текущем
  плейсхолдере — `make_icon()` в generate-app-images.py) — можно развивать
  дальше или заменить на что-то более узнаваемое под "flip"-концепцию
  (монетка/переворот, стрелки вверх-вниз).

## Что нужно

1. **Wordmark** — логотип-надпись "FlipTheMeme" (или "Flip The Meme" —
   на выбор дизайнера, но в коде/доменах пишем слитно). Должен читаться
   и на чёрном фоне, и потенциально на светлом (шапка сайта сейчас тёмная,
   но не факт что навсегда).
2. **Отдельный знак/марк** — то, что раньше было "MP" (сейчас временно
   заменено на "FM" в плейсхолдере). Нужен нормальный компактный символ,
   узнаваемый в 16×16 favicon — двух букв может быть недостаточно на таком
   размере, стоит подумать про чисто графический знак.
3. Обе версии должны работать в квадратном формате (иконка/сплэш) и в
   широком 1200×630 (OG/embed, там ещё есть теглайн + UP/DOWN индикатор,
   см. текущий `og-cover.png`/`embed.png` для компоновки-референса).

## Что НЕ входит в этот ТЗ

- Ончейн-имена NFT/LP-токенов (GenesisNFT/BadgeNFT/LiquidityPool) — отдельная
  тема, ждёт передеплоя контрактов (Part B, см. память проекта).
- Артворк самих NFT (Genesis/Badges) — уже описан отдельно в
  `docs/nft-artwork-spec.md`, не путать с этим файлом.

## Как обновить, когда есть финальный арт

Просто заменить 5 PNG-файлов в `frontend/public/` под теми же именами
(тот же размер/формат) и передеплоить (`vercel --prod` из `frontend/`) —
никаких изменений в коде не требуется, все ссылки уже указывают на эти пути.
